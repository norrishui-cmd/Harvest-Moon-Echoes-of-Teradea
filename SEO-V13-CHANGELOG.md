## Page parity

- Every localized FAQ uses the same information architecture as its English source page.
- Each page includes a hero answer, quick-answer callout, three evidence points, confirmation boundary, primary source, related questions, table of contents, FAQPage schema, Breadcrumb schema and reciprocal hreflang.
- Every page keeps the full two-line site name, language dropdown and AdSense configuration.

## Evidence policy

- Uses Natsume title, preorder and first-trailer announcements, the live Natsume Store listing, and current retailer screenshot evidence.
- Does not infer gifts, birthdays, character roles, quest steps, maps, technical performance, regional unlock times or unavailable editions.
- No crop, recipe, fish, gift or quest-detail database was opened because the official evidence set has not materially expanded.
