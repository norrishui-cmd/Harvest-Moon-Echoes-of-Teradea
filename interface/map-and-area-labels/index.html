Quick answer

The captured interface surfaces both broader region names and more specific area labels, including Bloomfield Village, Bloomfield Park, Wolf Hill, and Tornado Island.

How this connects to the game

The labels justify a nested location database rather than one flat list. Post-launch mapping can assign parent region, entrance, coordinates, services, hazards, and connected routes.
