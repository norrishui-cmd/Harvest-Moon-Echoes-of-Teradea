Select Song Control

What the DocPad Select Song prompt confirms about music interaction before launch.

Quick answer

The DocPad screenshot includes a Select Song action, indicating that players can choose music in at least one captured context.

What the published evidence shows

01

Select Song appears as an explicit control label.

02

It is displayed alongside cooking, sleeping, outfit, and Photo Mode actions.

03

The prompt does not name a track, playlist, instrument, or unlock condition.

How this connects to the game

This may support a music-selection or ambient-control feature, but the responsible interpretation is limited to the visible action. A later guide can add track lists and exact use conditions.
