Change Outfit Control and Customization

Evidence for the Change Outfit action and the limits of what it proves about character customization.

Quick answer

A visible DocPad control names Change Outfit, confirming an outfit-change action in the captured build.

How this connects to the game

The action supports a focused customization guide without claiming hairstyles, body editing, dyes, transmog, or clothing bonuses. Launch verification can add access points and wardrobe rules.
