Is Combat a Confirmed Core System?

Natsume confirms dangerous wild animals and tells players to evade and escape them, but it has not presented a weapon-based combat system as a core feature.

Quick answer

Natsume confirms dangerous wild animals and tells players to evade and escape them, but it has not presented a weapon-based combat system as a core feature.

Confirmed evidence

  • Wolves, bears, and tigers are hazards
  • getting caught causes item loss and a return to the farm
  • movement and companions support traversal.
  • Primary source: Natsume title announcement, dated 2026-03-11.

How to use this answer
