Should Demo Guides List Save-Transfer Steps Now?

Quick answer

No. Without an announced public demo, there is no build pair, platform rule, or save path that can be tested and documented.

Confirmed evidence

  • The official news index has no demo announcement
  • the product page has no trial terms

How to use this answer

Publish save-transfer steps only after Natsume or a platform listing defines them and a reproducible test confirms them.

1

Check the dated first-party source.

2

Separate the confirmed fact from platform, retailer, or story assumptions.

3

Recheck the live listing before acting on changing data.

What this does not confirm

Generic instructions copied from another Harvest Moon game could mislead players or overwrite the wrong save data.
